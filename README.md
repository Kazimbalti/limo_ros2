# limo_ros2

ROS 2 workspace for the AgileX LIMO robot — description/URDF, Gazebo simulation, navigation, and trajectory-tracking coursework packages, built for **ROS 2 Humble** on Ubuntu 22.04.

## Packages

| Package | Description |
|---|---|
| `limo_description` | URDF/xacro models and meshes for the LIMO (differential, Ackermann, mecanum, tracked variants) |
| `limo_gazebosim` | Gazebo simulation worlds, models, and launch files for the LIMO |
| `limo_msgs` | Custom message definitions (`LimoStatus`) |
| `trajectory_skeleton` | Skeleton controller for trajectory-tracking exercises |
| `trajectory_referee` | Records and scores trajectory-tracking runs against reference routes |
| `example_codes` | Example nodes: OpenCV, TF, localisation, navigation, controllers |
| `KV6022_assessment` | Coursework assessment package (navigation, waypoint following, pothole detection) |

## Prerequisites

- Ubuntu 22.04
- [ROS 2 Humble](https://docs.ros.org/en/humble/Installation/Ubuntu-Install-Debs.html) (`ros-humble-desktop` recommended)
- Gazebo (installed with `ros-humble-desktop`) and `ros-humble-gazebo-ros`, `ros-humble-gazebo-plugins`
- `colcon` build tools

```bash
sudo apt update
sudo apt install ros-humble-desktop ros-humble-gazebo-ros ros-humble-gazebo-plugins \
    ros-humble-joint-state-publisher ros-humble-joint-state-publisher-gui \
    ros-humble-xacro ros-humble-rviz2 \
    python3-colcon-common-extensions
```

## Setup

1. Clone this repository — it already contains a `src/` folder laid out as a ROS 2 workspace:

   ```bash
   git clone https://github.com/Kazimbalti/limo_ros2.git ~/limo_ws
   cd ~/limo_ws
   ```

2. Install any remaining dependencies via `rosdep`:

   ```bash
   sudo rosdep init   # skip if already initialised
   rosdep update
   rosdep install --from-paths src --ignore-src -r -y
   ```

3. Build the workspace:

   ```bash
   cd ~/limo_ws
   colcon build --symlink-install
   ```

4. Source the workspace (add to `~/.bashrc` to make this permanent):

   ```bash
   source ~/limo_ws/install/setup.bash
   ```

## Usage

**Visualise the robot model in RViz:**

```bash
ros2 launch limo_description display_models_diff.launch.py
```

**Launch the Gazebo simulation** (pick the drive variant):

```bash
ros2 launch limo_gazebosim limo_gazebo_diff.launch.py
ros2 launch limo_gazebosim limo_gazebo_ackerman_drive.launch.py
ros2 launch limo_gazebosim limo_gazebo_mecanum_drive.launch.py
ros2 launch limo_gazebosim limo_gazebo_track_drive.launch.py
```

**Run navigation / localisation examples:**

```bash
ros2 launch example_codes limo_map_server.launch.py
ros2 launch example_codes limo_localisation.launch.py
ros2 launch example_codes limo_navigation.launch.py
```

**Trajectory tracking exercise:**

```bash
ros2 launch trajectory_skeleton view_robot.launch.py
ros2 run trajectory_skeleton trajectory_tracking_controller
ros2 run trajectory_referee trajectory_publisher
```

**KV6022 assessment:**

```bash
ros2 launch KV6022_assessment limo_navigation.launch.py
```
